【 ملف .env — كل المفاتيح في مكان واحد 】

عدّل ملف .env مباشرة ثم أعد التشغيل (على Vercel/Railway: نفس
المتغيرات تُضاف في Settings → Environment Variables):
Modifiez directement le fichier .env puis redémarrez (sur Vercel/
Railway: mêmes variables dans Settings → Environment Variables):

1) قاعدة البيانات / Base de données:
     MONGODB_URI=mongodb://127.0.0.1:27017     (أو / ou MongoDB Atlas)
     MONGODB_DB=happy_inside_experience

2) حساب الأديمن / Compte administrateur:
     ADMIN_PHONE=0555555555
     ADMIN_PASSWORD=HappyInside@2026
     ADMIN_FULLNAME=مدير الموقع / Administrateur
   ✔ يُطبَّق فورًا حتى لو كانت القاعدة مهيأة سلفًا —
     غيّر الرقم/كلمة المرور وأعد التشغيل فقط.
   ✔ Synchronisé automatiquement à chaque démarrage,
     même si la base existe déjà.

3) مفتاح الجلسات / Secret des sessions:
     AUTH_SECRET=<مولَّد عشوائيًا / généré aléatoirement>
   ⚠ لا تشاركه مع أحد / ne le partagez jamais
     openssl rand -hex 48

4) أمان الكوكي / Sécurité du cookie (اختياري / optionnel):
     COOKIE_SECURE=true|false
   افتراضيًا آمن (Secure) في الإنتاج — اضبط false فقط للـ HTTP الذاتي.
   Secure par défaut en production — false uniquement en HTTP simple.

5) إشعارات Push / Notifications push (VAPID):
     VAPID_PUBLIC_KEY=<مولَّدة / générée>
     VAPID_PRIVATE_KEY=<مولَّدة / générée>
     VAPID_SUBJECT=mailto:contact@happyinside-experience.dz
   لإعادة التوليد / pour régénérer:
     npm exec -p web-push -- web-push generate-vapid-keys

6) معلومات التواصل (أول تهيئة فقط — ثم من لوحة التحكم):
   Contact (1er lancement uniquement — ensuite via le
   tableau de bord admin):
     WHATSAPP_NUMBER / CONTACT_EMAIL / FACEBOOK_URL / INSTAGRAM_URL

7) المساعد الذكي (اختياري — للنشر السحابي):
   Assistant intelligent (optionnel — déploiement cloud):
     AI_API_URL  = https://api.openai.com/v1   (أو Groq / OpenRouter)
     AI_API_KEY  = sk-...
     AI_MODEL    = gpt-4o-mini
   إن تُرك فارغًا يرد المساعد برسالة توضيحية لطيفة دون أخطاء.
   Si vide, l'assistant répond avec un message de repli gracieux.
